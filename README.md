
事件图谱规则逻辑总结

一、布尔组合逻辑

用于判断多个条件之间的组合关系。

AND：多个条件同时成立才触发。
例如：同一企业短期内出现大额贷款、资金快速转出、关联方接收资金 → 判断为疑似资金空转或利益输送。

OR：多个条件满足其一即可触发。
例如：企业频繁变更法人，或注册地址异常，或涉诉信息突然增加 → 触发企业风险关注。

NOT：排除不应触发的情况。
例如：资金大额流转，但不是正常贸易付款、不是历史稳定合作对象 → 才进一步判断为异常资金流。

复合布尔逻辑：AND / OR / NOT 嵌套使用。
例如：“大额贷款 AND 短期转出 AND 关联方接收”
OR
“空壳公司 AND 多层转账 AND NOT 正常经营流水”
→ 判断为疑似黑产资金链。

二、时序逻辑

用于判断事件发生的先后、窗口、持续和超时关系。

顺序逻辑：A 先发生，B 后发生。
例如：企业先获得贷款，随后资金转入多家关联公司，再回流到实际控制人账户。

窗口逻辑：多个事件必须在规定时间内发生。
例如：30 天内出现贷款到账、资金分拆转出、多级账户流转 → 判断为疑似资金腾挪。

持续逻辑：某种异常状态持续一段时间才触发。
例如：某账户连续多日夜间高频收款、分散转账 → 判断为疑似跑分账户。

超时逻辑：某事件发生后，规定时间内没有后续合理事件。
例如：企业获得大额贷款后，长期没有采购、生产、纳税等经营行为 → 判断为贷款用途异常。

因果链逻辑：形成“原因—过程—结果”的链条。
例如：虚假贸易合同 → 银行放款 → 多层转账 → 资金回流 → 构成疑似骗贷链路。

三、结构流转逻辑

用于表达多个事件如何汇聚，或者一个事件如何分流。

Join：多个分支汇聚后才触发判断。
例如：工商异常、资金异常、交易异常、关联关系异常同时汇聚 → 生成企业综合风险事件。

Split：一个事件触发多个后续分析分支。
例如：发现疑似黑产账户后，同时分析其资金来源、下游收款账户、设备指纹、登录 IP、关联商户。

AND-Split：一个风险事件并行触发多个动作。
例如：疑似洗钱交易出现后，同时触发账户冻结建议、人工复核、关系图谱扩展。

OR-Split：一个风险事件进入不同处置路径。
例如：异常交易可进入反洗钱审查、欺诈审查、信贷风控审查中的一种或多种。

四、上下文约束逻辑

用于限定规则适用范围，防止错误关联。

同主体上下文：判断事件是否属于同一企业、同一账户或同一实际控制人。

同区域上下文：判断交易、注册地、经营地是否存在异常跨区关系。

同时间尺度上下文：短期高频行为与长期行为需区分。

同关系上下文：资金流、股权关系、亲属关系需在同一图谱语境下关联。

同业务上下文：正常贸易、工资发放等不能误判为异常。

例如：A 企业贷款后资金转给 B，B 再转给 C，只有在 C 与 A 存在控制关系时，才判断为利益输送。
